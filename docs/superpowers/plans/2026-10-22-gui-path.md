# GUI PATH and daemon start Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `herdbot doctor` and `herdbot setup` give the right answers when run from the menu bar app (a GUI process with a bare `PATH`), and `setup` does not return until the daemon is actually up.

**Architecture:** A new `shellenv.rs` computes an *effective PATH*: the process `PATH`, then the user's interactive login shell `PATH`, then a few well-known directories that exist. `doctor`, `setup` and `service install` use it instead of `std::env::var("PATH")`. The shell lookup costs about 1.7 s on the author's machine, so it is cached in `.state/shell-path.json` for 10 minutes. `setup`'s `service` and `restart-daemon` fixes wait (up to 15 s) for the daemon to answer before reporting success.

**Tech Stack:** Rust 2024, std only (no new crates). Tests are inline over pure functions; no environment mutation in tests.

## Evidence (reproduced 2026-10-22)

- `env -i HOME=$HOME PATH=/usr/bin:/bin:/usr/sbin:/sbin /Applications/Herdbot.app/Contents/Helpers/herdbot doctor` prints `FAIL harnesses none of claude, codex, cursor-agent, pi is on PATH` and `warn cli-link no herdbot on PATH`, while all four harnesses and `/opt/homebrew/bin/herdbot` exist. The same binary in a terminal is all ok.
- `zsh -lc 'echo $PATH'` (login, not interactive) does NOT include `/opt/homebrew/bin` on that machine (Homebrew's `shellenv` is in `.zshrc`); `zsh -ilc` from `env -i HOME=… PATH=/usr/bin:/bin` does, in about 1.7 s. So the shell must be run interactive and login.
- `service::install` records `std::env::var("PATH")` in the launchd plist (`service.rs`, the `env` vec). Run from the app, that is the bare `PATH`, so the daemon could not spawn any harness.
- Likely (not reproduced): "the daemon takes a couple of tries to go green" is a race: `setup --only service` returns as soon as `launchctl bootstrap` returns, the app refreshes `doctor` immediately, and the daemon has not bound its lock socket yet; the next refresh is 60 s away or the user presses the fix again. Task 3 removes the race either way.

## Global Constraints

- No new dependencies. macOS only.
- Never run `herdbot service install|uninstall`, `herdbot setup` without `--only`, `herdbot uninstall`, or `launchctl` against the real launchd: the running daemon `dev.herdbot.daemon` would be replaced. - The `doctor --json` shape and check ids do not change.
- Commits: conventional messages, no AI attribution, explicit `git add` paths, no push.

```rust
//! The PATH a user would see in a terminal, for processes that did not start from one. The menu bar
//! app, launchd and anything started from Finder inherit `/usr/bin:/bin:/usr/sbin:/sbin`, which finds
//! none of the harness CLIs. `doctor`, `setup` and `service install` use `effective_path` instead.

use std::io::Read;
use std::path::PathBuf;
use std::process::{Command, Stdio};
use std::time::{Duration, Instant};

use serde::{Deserialize, Serialize};

use crate::home;

const MARK: &str = "__HERDBOT_PATH__";
const CACHE_SECS: i64 = 600;
const SHELL_TIMEOUT: Duration = Duration::from_secs(5);

#[derive(Serialize, Deserialize)]
struct Cached {
    at: i64,
    path: String,
}

pub fn parse_marked(output: &str) -> Option<String> {
    let start = output.find(MARK)? + MARK.len();
    let end = start + output[start..].find(MARK)?;
    let path = &output[start..end];
    (!path.is_empty()).then(|| path.to_owned())
}

/// `current` first (a terminal's own PATH stays authoritative), then the shell's, then extras;
/// each directory once, in first-seen order.
pub fn merge_paths(current: &str, shell: Option<&str>, extras: &[PathBuf]) -> String {
    let mut seen: Vec<PathBuf> = Vec::new();
    let all = std::env::split_paths(current)
        .chain(shell.into_iter().flat_map(std::env::split_paths))
        .chain(extras.iter().cloned());
    for dir in all {
        if !dir.as_os_str().is_empty() && !seen.contains(&dir) {
            seen.push(dir);
        }
    }
    seen.iter().map(|d| d.to_string_lossy()).collect::<Vec<_>>().join(":")
}

pub fn cache_fresh(at: i64, now: i64) -> bool {
    at <= now && now - at <= CACHE_SECS
}

fn supports_ilc(shell: &str) -> bool {
    matches!(
        std::path::Path::new(shell).file_name().and_then(|n| n.to_str()),
        Some("zsh" | "bash")
    )
}

/// Run the user's interactive login shell and read its PATH. None on any failure or after 5 s.
pub fn login_shell_path() -> Option<String> {
    let shell = std::env::var("SHELL").unwrap_or_else(|_| "/bin/zsh".into());
    if !supports_ilc(&shell) {
        return None;
    }
    let mut child = Command::new(&shell)
        .args(["-ilc", &format!("printf '{MARK}%s{MARK}' \"$PATH\"")])
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::null())
        .spawn()
        .ok()?;
    let mut stdout = child.stdout.take()?;
    let reader = std::thread::spawn(move || {
        let mut text = String::new();
        let _ = stdout.read_to_string(&mut text);
        text
    });
    let started = Instant::now();
    loop {
        match child.try_wait() {
            Ok(Some(_)) => break,
            Ok(None) if started.elapsed() < SHELL_TIMEOUT => std::thread::sleep(Duration::from_millis(20)),
            _ => {
                let _ = child.kill();
                let _ = child.wait();
                break;
            }
        }
    }
    parse_marked(&reader.join().ok()?)
}

fn extras() -> Vec<PathBuf> {
    let home = home::home_dir();
    [
        PathBuf::from("/opt/homebrew/bin"),
        PathBuf::from("/opt/homebrew/sbin"),
        PathBuf::from("/usr/local/bin"),
        home.join(".local/bin"),
        home.join(".cargo/bin"),
    ]
    .into_iter()
    .filter(|dir| dir.is_dir())
    .collect()
}

fn cache_path() -> PathBuf {
    home::root().join(".state").join("shell-path.json")
}

/// The process PATH plus the login shell's plus well-known directories. `fresh` ignores the cache
/// (setup uses it; doctor, which the app runs every minute, does not).
pub fn effective_path(fresh: bool) -> String {
    let current = std::env::var("PATH").unwrap_or_default();
    let now = home::now();
    let cached = (!fresh)
        .then(|| home::read_json::<Cached>(&cache_path()))
        .flatten()
        .filter(|c| cache_fresh(c.at, now))
        .map(|c| c.path);
    let shell = cached.or_else(|| {
        let found = login_shell_path();
        if let Some(path) = &found {
            let _ = home::write_json(&cache_path(), &Cached { at: now, path: path.clone() });
        }
        found
    });
    merge_paths(&current, shell.as_deref(), &extras())
}
```

```rust
use std::time::{Duration, Instant};

/// Poll `probe` every `interval` until it passes or `timeout` passes. The probe runs at least once.
pub fn wait_until(timeout: Duration, interval: Duration, mut probe: impl FnMut() -> bool) -> bool {
    let started = Instant::now();
    loop {
        if probe() {
            return true;
        }
        if started.elapsed() >= timeout {
            return false;
        }
        std::thread::sleep(interval);
    }
}

/// The daemon answers on its lock socket and reports this binary's version.
fn daemon_current() -> bool {
    std::os::unix::net::UnixStream::connect(home::daemon_lock()).is_ok()
        && home::read_daemon_info().is_some_and(|info| info.version == env!("CARGO_PKG_VERSION"))
}

fn wait_for_daemon(done: String) -> Result<String> {
    if wait_until(Duration::from_secs(15), Duration::from_millis(250), daemon_current) {
        return Ok(done);
    }
    let log = home::root().join(".state/daemon.log");
    let tail: Vec<String> = std::fs::read_to_string(&log)
        .unwrap_or_default()
        .lines()
        .rev()
        .take(5)
        .map(str::to_owned)
        .collect::<Vec<_>>()
        .into_iter()
        .rev()
        .collect();
    Err(format!("the daemon did not come up within 15 s; last log lines ({}):\n{}", log.display(), tail.join("\n")).into())
}
```

In `run_fix`, change the two arms to `"service" => service::install().and_then(wait_for_daemon)` and `"restart-daemon" => service::restart().and_then(wait_for_daemon)`. `daemon.json` is written by the daemon right after it takes the lock, so a stale file from the previous run with the same version can satisfy the version test before the new daemon is up; the socket test is what proves liveness (the old daemon's socket is gone during a restart). If this proves flaky in the live check, compare the `pid` in `daemon.json` with the one launchd reports instead and say so.
